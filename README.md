# wernah.com

Plain static HTML. No build step, no dependencies.

- **Edit:** `index.html` (content) and `stylesheets/all.css` (styles).
- **Preview:** `python3 -m http.server 8000`, then open http://localhost:8000.
- **Publish:** commit and push to `master`. GitHub Pages serves this repo directly; `CNAME` maps it to wernah.com. Live within a minute or two.
